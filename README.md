# BrickGame_v1

**BrickGame_v1** - консольная игра в стиле Tetris, реализованная на языке C с использованием структурного программирования и библиотеки `ncurses`.

Игра воспроизводит классическую механику тетриса: пользователи управляют падающими фигурами, собирают линии, набирают очки и проходят уровни.

## Реализованные возможности

- Падение фигур различной формы с игрового поля;
- Вращение фигур;
- Перемещение фигуры по горизонтали;
- Ускоренное падение фигур при нажатии кнопки;
- Показ следующей фигуры;
- Уничтожение заполненных линий и смещение оставшихся блоков вниз;
- Завершение игры при достижении верхнего ряда;
- Подсчет очков:  
  - 1 линия 100 очков  
  - 2 линии 300 очков  
  - 3 линии 700 очков  
  - 4 линии 1500 очков
- Система уровней: каждые 600 очков уровень повышается, увеличивая скорость падения фигур (максимум 10 уровней);
- Хранение рекордов между сессиями игры (файл или встроенная СУБД);
- Управление с помощью клавиш консоли:
  - Стрелка влево/вправо - движение фигуры;
  - Стрелка вниз - ускоренное падение;
  - Действие - вращение фигуры;
  - Начало игры, пауза, завершение игры.

## Архитектура

- Конечный автомат управляет логикой игры с состояниями:
  - Старт
  - Спавн фигуры
  - Перемещение
  - Сдвиг вниз
  - Соединение (остановка фигуры и проверка линий)
  - Игра окончена
- Игровое поле представлено в виде матрицы 10x20.
- Код разделен на:
  - Логику игры (src/brick_game/tetris)
  - Терминальный интерфейс (src/gui/cli)
